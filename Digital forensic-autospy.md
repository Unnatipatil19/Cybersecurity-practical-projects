# Digital Forensics Investigation Using Autopsy

## Objective
To investigate a forensic disk image using Autopsy and identify useful digital evidence such as files, metadata, timestamps, and other artifacts.

## Tool Used
- Autopsy
- E01 Forensic Disk Image

## Procedure
1. Created a new case in Autopsy.
2. Added the E01 forensic image as the data source.
3. Allowed Autopsy to perform the required analysis.
4. Examined the Analysis Results, including interesting files and other artifacts.
5. Selected files and checked their metadata.
6. Examined Created, Modified, and Accessed timestamps.
7. Generated an HTML forensic report containing the investigation results.

## Findings
- The forensic image was successfully analyzed.
- Autopsy identified different categories of digital artifacts.
- File metadata and timestamps were examined.
- Analysis results provided useful information about the contents of the forensic image.
- An HTML forensic report was successfully generated.
